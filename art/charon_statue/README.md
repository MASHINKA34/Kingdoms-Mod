# Статуя Харона — вариант B

Редактируемая 3D-модель по согласованному концепту: каменная статуя со мхом,
глубоким капюшоном, веслом и оригинальным Жетоном Харона из Kingdoms.

## Файлы

- `charon_statue_B.bbmodel` — основной проект Blockbench, формат «Общая модель» (free).
  Обе текстуры встроены: файл можно передавать отдельно и открывать в Blockbench.
- `charon_statue_B.gltf` — дополнительный экспорт для просмотра или импорта в 3D-редактор.
  Геометрия и текстуры встроены, внешние файлы не требуются.
- `textures/charon_statue_atlas.aseprite` — исходник текстуры с тремя слоями:
  камень, трещины и мох.
- `textures/charon_statue_atlas.png` — цветовой атлас 512 × 512.
- `textures/charon_token.png` — точная копия существующей текстуры жетона 16 × 16.
- `textures/charon_*_layer.png` — отдельные слои текстуры в PNG.
- `previews/charon_statue_B_sheet.png` — лист с реальными видами модели из Blockbench.
- `previews/hero.png`, `front.png`, `side.png`, `back.png` — виды на прозрачном фоне.
- `source/build_charon_statue.py` — воспроизводимая геометрия и отрисовка текстуры.
- `source/geometry.json` — размеры деталей, UV и распределение по группам.
- `validation.json` — результаты проверки модели.

## Размер и устройство

Масштаб: **16 единиц = 1 блок**. Габариты: **32 × 48 × 32 единицы по X/Y/Z**,
то есть **2 блока в ширину, 2 в глубину и 3 в высоту**, включая постамент и весло.
Граница модели: X −16…16, Y 0…48, Z −16…16. Пол находится на Y = 0,
центр постамента — X = 0, Z = 0; передняя сторона смотрит в −Z.

109 редактируемых кубов, 8 именованных групп: постамент, мантия, наплечная часть,
капюшон, руки, весло, мох и жетон. UV камня — примерно 32 пикселя на блок.
Жетон объёмный: его контур повторяет непрозрачные пиксели оригинальной текстуры.
Изображение черепа и бирюзовые акценты сохранены без перерисовки.

Для правки текстуры откройте `.aseprite`, измените нужный слой, экспортируйте PNG
поверх `textures/charon_statue_atlas.png` и обновите эту текстуру в Blockbench.
После обновления сохраните `.bbmodel`, чтобы обновить встроенную копию.

## Интеграция в мод

Статуя зарегистрирована как `kingdoms:charon_statue` и доступна во вкладке Kingdoms.
Команда для получения: `/give @s kingdoms:charon_statue`.
Размещение занимает 2 × 2 × 3 блока, требует четырёх опорных блоков и свободного
места над ними. Конструкция поворачивается к игроку; разрушение любой части
убирает всю статую и при добыче подходящим инструментом даёт один предмет.

Игровая геометрия использует встроенный загрузчик OBJ NeoForge: модель разделена
на 12 частей по границам блоков. Коллизия и контур выделения рассчитаны по кубам
Blockbench с шагом 1/32 блока и сохранены для четырёх направлений. Для инвентаря,
рук и других способов отображения заданы отдельные масштаб и положение.
Готовые OBJ, JSON и текстуры в `src/main/resources` хранятся в Git, поэтому обычная
сборка мода не требует запуска Blockbench, Aseprite или Python.

После редактирования сохраните `.bbmodel`, повторно экспортируйте встроенный
`.gltf` из Blockbench и обновите PNG атласа. Затем из корня репозитория выполните
с установленными Python и NumPy:

```text
python tools/export_charon_statue.py
```

Экспортёр обновляет игровые модели, состояния блока, текстуру и коллизии.
Проверки ресурсов находятся в `CharonStatueAssetsTest`, игровые проверки
размещения, разрушения и отката установки — в `CharonStatueGameTests`.

Покупка жетона за шпоры, настройка цены оператором и рецепт крафта пока не
реализованы. Ориентир сложности будущего крафта из ТЗ — до Мшистых пещер.

## Воспроизведение исходников

Из корня репозитория, с установленным Python и Pillow:

```text
python art/charon_statue/source/build_charon_statue.py
```

Команда пересоздаёт PNG слоёв, цветовой атлас и `source/geometry.json`.
Сохранённые вручную изменения в PNG при этом заменяются; `.aseprite` и `.bbmodel`
скрипт не изменяет. Основная модель собрана и экспортирована через Blockbench MCP,
слои собраны и экспортированы через Aseprite MCP.

`source/make_preview.py` собирает лист из сохранённых видов модели; ему нужны
Pillow и шрифты Segoe UI из Windows. `source/validate_package.py` проверяет
исходники и создаёт архив для передачи художнику. Этот ZIP исключён из Git,
поскольку он дублирует содержимое каталога.
